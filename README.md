A fun Snake game built using HTML, CSS, and JavaScript. Control your snake, eat apples, and try to achieve the highest score!

## 🎮 Play the Game

🔗 [Play Sn@ke RUN](https://pateldhrupad011-sketch.github.io/snake-game/)

## 🕹️ How to Play

- Use the **arrow keys** to move your snake.
- Eat apples to grow your snake.
- Avoid eating yourself.
- You start with **3 lives**.
- Eating yourself costs you 1 life.

Try to survive and get the highest score!

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
