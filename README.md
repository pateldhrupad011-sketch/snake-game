Sn@ke RUN is a Snake game I made for Hackclub's PIXL hackathon. The goal in the game is to eat as many apples possible to grow your snake and reach to highest score without hitting yourself. The game gives 3 lives to the user, which can be lost if the snake hits it self or touches the red border line. I built it using HTML, CSS, and JavaScript while learning game development as a beginner

## Play the Game


 [Play Sn@ke RUN](https://pateldhrupad011-sketch.github.io/snake-game/)

## How to play - to play this game the user would have to use the arrow keys to redirect the snake to eat the apples while making sure not to hit yourself and not to touch the red borders 


# Why I made this: 
I made this game for Hack Club's PIXL hackathon. I'm still pretty new to coding, so I wanted to challenge myself by building a game instead of just following tutorials.

I had some trouble with things like creating the snake's circular face and apples, so I used AI to help me understand and work through those parts. Making this game helped me learn more about HTML, CSS, and JavaScript, and I got to see how different parts of code work together.
